# Sports Desk

A minimal Next.js + MDX blog scaffolded by Copilot. Designed for publishing sports articles written in Markdown.

## Run locally

1. Install dependencies

   npm install

2. Run dev server

   npm run dev

Open http://localhost:3000

## Add a post

Add a Markdown file to the `posts/` folder with frontmatter, for example:

---
title: "My article"
date: "2026-10-16"
excerpt: "A short summary"
---

Your article content...

## Deploy

1. Sign in to https://vercel.com with your GitHub account.
2. Import this repository and deploy. Vercel auto-detects Next.js.
