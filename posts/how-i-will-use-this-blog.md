This post explains the simple workflow for adding articles:

1. Create a new file in the `posts/` directory with a `.md` extension.
2. Add frontmatter with at least `title:` and `date:`.
3. Push the file to GitHub. If deployed on Vercel the article will appear automatically after build.

If you'd like, I can add a simple admin UI or connect a headless CMS so you can write posts through a web editor instead of editing files directly.
